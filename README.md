# Чат Легиона

Чат шахты и города игры «Легион» на [play.multidonate.ru](https://play.multidonate.ru) — панелью прямо в игре или отдельным окном. Есть два варианта: **расширение для браузера** (ничего больше ставить не нужно) и **userscript** для Tampermonkey / Violentmonkey. Код у них общий.

## Что умеет

- **Панель в игре** — кнопка «💬 Чат» слева внизу открывает чат сбоку, ширину можно тянуть за край. «⧉» выносит чат в отдельное окно.
- **Шахта, город и «🔀 Всё»** — чат шахты, вкладки города («Общий», «Торговля», «Достижения») со счётчиками новых и общая лента всего сразу по времени, с пометкой источника и фильтрами.
- **✉ Личные** — отдельная комната на новой личке игры: пишешь из любой комнаты, входить в город не нужно. Новые сообщения приходят мгновенно — бейдж, всплывашка «Ответить» в любой комнате и, по желанию, уведомление на рабочем столе 🔔. Список диалогов с превью и непрочитанными, переписка пузырями с днями и подгрузкой ранних, черновики, поиск, ✉ у ника, «@ник текст» из любой ленты. Вкладки собеседников общие с личкой игры.
- **Друзья** — друзья с онлайн-статусом («в шахте»), заявки (принять/отклонить), добавить в друзья, заблокировать/разблокировать, пожаловаться модераторам (снимок последних 30 сообщений).
- **Стримеры** — список каналов игры, 🔴 у тех, кто в эфире.
- **Модерация** — для админа и модераторов чата: «⋯» у сообщения (удалить, мут 5 мин – 7 дней или свой срок, бан навсегда, снять), панель 🔨 с ограничениями и модераторами, команды `/mute ник [минут]`, `/ban ник`, `/unban ник`, `/mod ник`, `/unmod ник`. Права проверяет сервер игры: без них инструментов не видно.
- **Стикеры** — 7TV, BTTV и FFZ канала картинками в ленте и панель выбора с поиском.
- **Пасты** — сохранённые сообщения с названиями.
- **Поверх окон** — кнопка 📌 в отдельном окне (Chrome и Edge 116+), компактный вид.
- **Темы** — светлая, тёмная или как в системе.

## Установка: расширение

Готовые пакеты — в папке [`dist`](dist):

| Браузер | Файл |
|---|---|
| Chrome, Edge, Opera, Яндекс Браузер | [legion-chat-chrome.zip](https://github.com/frebertor-sudo/legion-chat-window/raw/main/dist/legion-chat-chrome.zip) |
| Firefox 121+ | [legion-chat-firefox.zip](https://github.com/frebertor-sudo/legion-chat-window/raw/main/dist/legion-chat-firefox.zip) |

**Chrome / Edge / Opera / Яндекс:** распакуй zip в папку → открой `chrome://extensions` (в Edge — `edge://extensions`) → включи «Режим разработчика» → «Загрузить распакованное» → выбери папку. Папку потом не удаляй.

**Firefox:** без подписи Mozilla расширение ставится только до перезапуска браузера: `about:debugging` → «Этот Firefox» → «Загрузить временное дополнение» → выбери zip. Постоянная установка — после публикации в каталоге Firefox.

Расширение, поставленное из zip, само не обновляется: новую версию нужно поставить так же заново. Автообновления появятся после публикации в магазинах; до этого удобнее userscript.

## Установка: userscript (обновляется сам)

1. Поставь [Tampermonkey](https://www.tampermonkey.net/) или [Violentmonkey](https://violentmonkey.github.io/).
2. **Chrome 138 и новее:** `chrome://extensions` → Tampermonkey → «Сведения» → включи **Allow User Scripts** («Разрешить пользовательские скрипты»).
3. Открой ссылку и подтверди: **[установить legion-chat.user.js](https://raw.githubusercontent.com/frebertor-sudo/legion-chat-window/main/legion-chat.user.js)**

Обновления приходят сами: Tampermonkey проверяет новую версию раз в сутки.

Не ставь расширение и userscript одновременно — будут две кнопки и два чата.

## Куда ходит

Только на `play.multidonate.ru` под твоим собственным входом и в открытые сервисы стикеров: `api.ivr.fi`, `7tv.io`, `cdn.7tv.app`, `api.betterttv.net`, `cdn.betterttv.net`, `api.frankerfacez.com`. Никакие данные никуда больше не отправляются; настройки, пасты и личная переписка хранятся в браузере. Расширению не нужны особые разрешения — только доступ к страницам игры.

## Что важно знать

- Чтобы читать и писать в чат города, герой должен быть на Ярмарке канала. Если город уже открыт в игре, чат подхватывает его и героя не трогает. Если нет — спрашивает перед входом, а при закрытии выводит героя обратно.
- Писать в чат шахты можно, когда герой в шахте.
- Скрипт неофициальный и пользуется внутренним API игры: если разработчики что-то поменяют, чат может перестать работать до обновления.

## Сборка и выпуск версии

```
python3 tools/build.py
```

Собирает оба zip и копию userscript в `dist/`. Версия берётся из `@version` в `legion-chat.user.js`.

Новая версия: поднять `@version` → собрать → закоммитить в `main`. Новая версия сама запускает [публикацию](.github/workflows/publish.yml): сборка, Firefox Add-ons, Chrome Web Store, Microsoft Edge Add-ons и выпуск на GitHub с zip-файлами. Магазин, для которого в настройках репозитория нет ключей, пропускается. Тексты и картинки для карточек — в [`store/`](store/LISTING.md), как подключить магазины и ключи — [store/PUBLISHING.md](store/PUBLISHING.md), политика конфиденциальности — [PRIVACY.md](PRIVACY.md).
